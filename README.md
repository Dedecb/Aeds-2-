# 📗 Algoritmos e Estruturas de Dados II

Bem-vindo ao meu repositório! 🚀
Sou **André Luiz** e aqui registro meu aprendizado na disciplina de *Algoritmos e Estruturas de Dados II* da **PUC Minas**.
Este espaço reúne exercícios, provas e projetos desenvolvidos ao longo da matéria, organizados para acompanhar minha evolução e facilitar revisões futuras.

---

## 🎯 Objetivo

Este repositório tem como objetivo consolidar os conceitos avançados de estruturas de dados, com foco em:

- árvores (binárias, AVL, B-Trees)
- grafos e algoritmos de busca/caminho
- tabelas hash
- análise de complexidade e eficiência de algoritmos
- boas práticas de desenvolvimento em C/C++

---

## 🔖 Organização do Repositório

Os conteúdos estão organizados em três categorias principais:

- **exercicios/** → listas de exercícios propostas em aula

  * `lista-01/`
  * `lista-02/`

- **provas/** → avaliações da disciplina, agrupadas por bimestre

  * `prova-1/` → lista de revisão, prova teórica e prova prática do 1º bimestre
  * `prova-2/` → lista de revisão, prova teórica e prova prática do 2º bimestre

- **trabalhos/** → projetos maiores desenvolvidos ao longo do semestre

Essa organização permite acompanhar minha evolução ao longo da matéria.
